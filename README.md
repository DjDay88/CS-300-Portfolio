Reflection
What was the problem you were solving in the projects for this course?

The main problem I was solving was how to organize, store, search, and sort course information efficiently. Each project focused on using different data structures to manage data while making the program accurate and easy to use.

How did you approach the problem? Consider why data structures are important to understand.

I approached each project by first understanding the requirements and then choosing the data structure that best fit the problem. Learning about vectors, linked lists, hash tables, and binary search trees showed me that selecting the right data structure can improve both the speed and organization of a program.

How did you overcome any roadblocks you encountered while going through the activities or project?

The biggest roadblocks were debugging my code and making sure the program produced the correct output. I worked through these issues by testing my code often, fixing one problem at a time, and comparing my results with the expected output until everything worked correctly.

How has your work on this project expanded your approach to designing software and developing programs?

These projects helped me think more about planning before writing code. I learned that understanding the problem first and selecting the appropriate data structure makes software easier to develop and improves overall performance.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

This course taught me to write cleaner and more organized code by using meaningful variable names, separating tasks into functions, and keeping the program easy to follow. I now have a better understanding of how to create programs that are easier to maintain, update, and adapt for future projects.
